# ミュートワード フィルター

X / Yahoo!ニュース などで、指定したキーワードを含む記事・ポストを自動で非表示にする Chrome 拡張機能です。

## インストール（パッケージ化されていない拡張機能）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`ngword-blocker`）を選択する

読み込んだら、ツールバーのアイコン（🔇）からキーワードを追加してください。

## 使い方

- **ポップアップ**（アイコンをクリック）: ON / OFF、キーワードの追加・削除、このページでのブロック件数
- **設定ページ**（ポップアップの「すべての設定」）: キーワードの一括編集、非表示の方法、対象サイト、ブロック実績、設定の書き出し / 読み込み

### キーワードの書き方

| 書き方 | 例 | 挙動 |
| --- | --- | --- |
| 通常 | `増税` | 部分一致。大文字小文字・全角半角を区別しない |
| 正規表現 | `/(増税｜値上げ)/` | `/` で囲むと正規表現。`/…/i` のようにフラグも指定可 |

### 非表示の方法

- **折りたたむ**（既定）: 細いバーだけ残し、「表示する」で中身を確認できる
- **完全に消す**: 要素ごと消し、痕跡を残さない

### 対象サイト

既定で対応しているのは X (Twitter) / Yahoo! JAPAN（ニュース・トップ・リアルタイム検索）/ Google ニュース / はてなブックマークです。

「その他のサイト（汎用モード）」を ON にすると、すべてのページで `article` / `li` を 1 件分とみなしてフィルターします。ON にするときだけ「すべてのサイトへのアクセス」の許可を求めます（OFF にすると動的に登録したスクリプトも解除されます）。

## ファイル構成

```
manifest.json          Manifest V3
src/common.js          設定のデフォルト・ストレージ・マッチング処理（全体で共用）
src/adapters.js        サイトごとの「1件分の要素」の定義
src/content.js         DOM 監視と非表示処理
src/content.css        折りたたみバーのスタイル
src/background.js      バッジ・実績集計・汎用モードの動的登録
src/options.*          設定ページ
src/popup.*            ツールバーのポップアップ
src/ui.css             設定ページ / ポップアップ共通のスタイル
tools/make-icons.mjs   アイコン PNG の生成（依存ライブラリなし / node tools/make-icons.mjs）
```

## 仕組みのメモ

- 判定は要素の `textContent` に対して行い、NFKC 正規化 + 小文字化してから部分一致を見ます。
- `MutationObserver` で DOM の変化を拾い、約 120ms のデバウンス後にスキャンします。無限スクロールにも追従します。
- 入れ子になった要素は「より内側に同じセレクタの要素がない」ものだけを 1 件として扱うため、リスト全体が丸ごと消えることはありません。
- 設定は `chrome.storage.sync`、ブロック実績は `chrome.storage.local` に保存します。設定を変えると開いているタブへ即時反映されます。
